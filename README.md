# NihongoMaster - Android Native App

Interactive Japanese learning platform for JLPT N5, N4, N3 & N2 written in Kotlin and Jetpack Compose.

## Features
- **Grammar Hub (文法)**: In-depth Bunpou patterns from Shin Kanzen Master, Sou Matome, and Minna no Nihongo with formulas, nuances, caution notes, and Furigana example sentences.
- **Vocab Hub (語彙)**: Goi cards with pitch accents, antonyms/synonyms, parts of speech, and bookmarking.
- **Kanji Hub (漢字)**: Kanji with stroke counts, radicals, Onyomi, Kunyomi, and Jukugo compound words.
- **SRS Flashcards (Anki SM-2 & Quizlet Modes)**: Spaced repetition flip flashcards, multiple choice quizzes, and speed tile matching game.
- **JLPT Timed Exam Simulation**: Realistic timed exam environment with ★ Star Question builder and Dokkai reading passages.
- **Analytics & Daily Streaks**: Mastery tracking across JLPT sections and daily study habits.
- **AI Sensei**: Conversational Japanese learning assistant.
